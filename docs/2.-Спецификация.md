# 1.	Введение
## 1.1	Назначение 
Приложение – редактор характеристик юнитов в компьютерной игре Medieval 2: Total War «Арена» (версия 1.0). Спецификация предназначена для разработчиков и тестировщиков.
## 1.2	Соглашения, принятые в документах
Спецификация требований написана шрифтом Times New Roman (12 кегль); структура составлена многоуровневым списком.
## 1.3	Границы проекта
Приложение нацелено на обычных пользователей для ежедневного использования (как для игры, в целях развлечения, так и для реконструкции исторических сражений).

# 2.	Общее описание
## 2.1.	 Общий взгляд на продукт
Приложение «Арена» является абсолютно новым продуктом.
## 2.2.	Классы и характеристики пользователей
Продукт предназначен для повседневного использования любыми пользователями, которые хотят развлечься и скрасить свой досуг, а также для создателей исторических реконструкций и видеороликов. Это могут быть люди разных возрастов и социального положения.
## 2.3.	 Операционная среда
Приложение «Арена» разработано для операционных систем Windows 10 и выше, а также MacOS Sequoia и выше. Для использования не требуется доступ к сети Интернет.
## 2.4.	 Ограничения дизайна и реализации
Приложение разрабатывается в среде разработки IntelliJ IDEA на языке программирования Java с использованием сторонних приложений (например, SceneBuilder).
## 2.5.	 Предположения и зависимости
Для установки приложения не требуется установка иного программного обеспечения. Приложение работает независимо.
# 3.	Функции системы
## 3.1.	 Функция системы
Развлечение пользователя, помощь в реконструкции исторических сражений.
## 3.2.	 Описание
Программа представляет собой окно главного меню с тремя кнопками перехода в другие окна и строкой ввода адреса корневой папки игры. При вводе адреса корневой папки игры программа работает с файлами в этой папке. При нажатии кнопки «Изменение характеристик юнита» открывается окно редактирования характеристик юнита. В этом окне необходимо ввести наименование юнита и вводить его новые характеристики, после чего нажать кнопку «Применить» для изменения характеристик. При нажатии кнопки «Сравнение юнитов» открывается окно сравнения юнитов. В нём необходимо ввести названия юнитов, характеристики которых нужно сравнить, и нажать кнопку «Сравнить» для получения результатов сравнения в поле вывода результатов. При нажатии кнопки «Расчёт пропорций войск» открывается окно расчёта пропорций реальных войск к игровым. В данном окне нужно ввести общую численность войск, участвовавших в реальном сражении, численность одного отряда из этих войск и общую численность войск для реконструируемого сражения, чтобы узнать, сколько воинов должно быть в соответствующем отряде игрового сражения (либо наоборот, ввести численность какого-либо отряда для расчёта общего количества воинов в игровом сражении). При нажатии кнопки «Рассчитать пропорции» в поле вывода результатов выводится результат. Каждое из трёх окон имеет кнопки сброса и выхода в меню.
## 3.3.	 Функциональные требования
- Просмотр главного меню <br>
  - поиск корневой папки игры
  - выбор действий (переход к окнам)
- Просмотр окна изменений характеристик юнита <br>
выбор окна изменений характеристик юнита:
  - поиск юнита
  - редактирование характеристик юнита
  - сброс введённых значений
  - выход в главное меню
- Просмотр окна сравнения юнитов <br>
выбор окна сравнения юнитов:
  - поиск юнитов
  - сравнение характеристик юнитов
  - сброс введённых значений и результатов
  - выход в главное меню
- Просмотр окна расчёта пропорции войск <br>
выбор окна расчёта пропорции войск:
  - расчёт пропорций численности войск
  - сброс введённых значений и результатов
  - выход в главное меню
# 4.	Требования к данным
## 4.1.	Словарь данных
Главное меню: тип данных string
Окно редактирования юнита: тип данных int
Окно сравнения юнитов: тип данных int
Окно расчёта пропорций войск: тип данных int
## 4.2.	 Отчёты
Приложение выводит информацию об ошибках в консоли редактора IntelliJ IDEA и формирует log-файл.
## 4.3.	 Получение, целостность, хранение и утилизация данных
Данное приложение – простой рабочий инструмент, минимальная рабочая версия, использующая базу данных лишь для хранения пути к корневой папке игры, а потому пользователем не вводятся никакие персональные данные (нет авторизации), а приложение эту информацию не получает, не хранит и не утилизирует.
# 5.	Требования к внешним интерфейсам
## 5.1.	 Пользовательские интерфейсы
Стандартные кнопки, шрифты, значки, цветовые схемы, размер и конфигурация экрана.
## 5.2.	 Интерфейсы ПО
Взаимодействие элементов интерфейса происходит с помощью стандартных методов. 
Выделены следующие нефункциональные требования: 
- простой и понятный интерфейс для удобства использования;
- эффективная обработка данных для быстродействия приложения;
- гарантия стабильной работы приложения на разных устройствах.
## 5.3.	 Интерфейсы оборудования
Приложение поддерживает следующие типы устройств: стационарные ПК и ноутбуки с операционными системами Windows 10 и выше, а также MacOS Sequoia и выше. Используются клавиатура и мышь/трекпад для управления курсором (чтобы поставить каретку ввода символов в нужное поле ввода), а также монитор для вывода изображения.
## 5.4.	 Коммуникационные интерфейсы
В данном приложении не требуется доступ к сети.
# 6.	Атрибуты качества
## 6.1.	 Удобство использования
Приложение имеет интуитивно понятный интерфейс, простой в использовании, доступный для освоения любому пользователю.
## 6.2.	 Производительность
Приложение нетребовательно к системе, имеет небольшой размер, поэтому проблем с производительностью не возникнет даже на слабых устройствах.
## 6.3.	 Безопасность
При использовании приложения регистрация не требуется, оно не собирает и не хранит никаких данных пользователя, является полностью безопасным с точки зрения политики конфиденциальности. Никакие разрешения не требуются.
## 6.4.	 Техника безопасности
В крайне редких случаях использование приложения может быть потенциально опасным в случае его использования во время зарядки ноутбука (короткое замыкание).
## 6.5.	 Другие атрибуты качества
Важным атрибутом качества является доступность приложения – оно доступно для скачивания по ссылкам с сервисов «Google Drive» и «Яндекс Диск» любому пользователю. 
# 7.	Требования по интернационализации и локализации
Приложение разработано исключительно для русскоговорящих пользователей в Российской Федерации, имеет только один язык – русский.
## 8.	Остальные требования
Приложение и пользование приложением не нарушают законодательства РФ (идея приложения разработана самим разработчиком, поэтому нарушение авторских прав невозможно).
