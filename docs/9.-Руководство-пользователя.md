# Руководство пользователя для приложения «Арена»

# 1.	Введение
## 1.1	Область применения 
Требования настоящего документа применяются при повседневном использовании приложения для реконструкции исторических сражений. 
## 1.2	Краткое описание возможностей
Десктопное приложение «Арена» предназначено для изменения характеристик юнитов в стратегической игре Medieval 2: Total War и её модификациях, а также для сравнения юнитов и расчёта численности войск при реконструкции исторических сражений в редакторе карт игры.
## 1.3	Уровень подготовки пользователя
Приложение нацелено на широкий круг пользователей, играющих в Medieval 2: Total War, а также для более подготовленных пользователей, занимающихся реконструкцией исторических сражений в редакторе игры.
## 1.4	Перечень эксплуатационной документации
Руководство пользователя.
# 2.	Назначение и условия применения
## 2.1	Виды деятельности и функции, для автоматизации которых предназначено приложение
Игра в Medieval 2: Total War и реконструкция исторических сражений.
## 2.2	Условия, при соблюдении которых обеспечивается применение приложения в соответствии с назначением
Персональный компьютер с ОС Windows 10 и выше и с MacOS Sequoia и выше, а также установленная игра Medieval 2: Total War. 
# 3.	Подготовка к работе
## 3.1	Состав и содержание дистрибутивного носителя данных
Для работы с приложением «Арена» необходимо следующее программное обеспечение: Windows 10 и выше, MacOS Sequoia и выше.
## 3.2	Порядок загрузки данных и программ
Перед началом работы с приложением «Арена» необходимо выполнить следующие действия:
1)	Открыть веб-браузер, дважды кликнув по его иконке на рабочем столе.
2)	Ввести в поисковую строку ссылку на скачивание приложения https://drive.google.com/file/d/1j6EkqsGePJ2-a0n_WdeorHJNmqsIu8si/view?usp=share_link (либо пройти по ссылке из данного документа), кликнуть по клавише Enter.
3)	На открывшейся странице Google Диск кликнуть по кнопке «Скачать».
4)	В папке «Загрузки» кликнуть дважды по иконке скаченного приложения (с расширением .jar). Приложение автоматически установится на компьютер.
## 3.3	Порядок проверки работоспособности
Для проверки работоспособности приложения необходимо выполнить следующие действия: кликнуть по иконке установленного приложения; если оно запустилось, значит приложение работает.
# 4.	Описание операций
## 4.1	Выполняемые функции и задачи 
Приложение «Арена» выполняет следующие функции: редактирование характеристик юнитов в игре Medieval 2: Total War и модах для неё, сравнение характеристик юнитов, расчёт пропорций реальной численности войск к игровой численности. Описание: приложение показывает параметры атаки и защиты юнитов из файла в корневой папке игры, сохраняет изменённые пользователем характеристики юнитов в текстовом файле; вычисляет параметры атаки и защиты двух юнитов, показывая, у какого юнита выше параметры атаки и защиты; вычисляет пропорцию соотношения игровой численности войск к реальной численности.

# 5.	Аварийные ситуации
В ходе разработки и тестирования приложения разработчиком выявлялись и устранялись все ошибки, поэтому к моменту релиза аварийных ситуаций не наблюдалось.
Для того, чтобы удалить приложение, необходимо удалить его корневую папку, распакованную из архива.
# 6.	Рекомендации по освоению
Рекомендуется пользоваться приложением после минимального ознакомления с игрой во избежание ошибок.
