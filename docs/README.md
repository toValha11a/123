## ⚙️ Возможности приложения

- 🔍 **Поиск юнита** по названию в файлах игры и отображение его иконки
- ✏️ **Редактирование характеристик** (атака, натиск, доспех, щит, умение защиты, дальность) с валидацией ввода
- ⚖️ **Сравнение двух юнитов** по атаке и защите
- 🧮 **Расчёт пропорций** реальной и игровой численности войск для реконструкции сражений
