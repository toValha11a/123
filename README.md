## Описание 
Некоторые игроки Medieval 2: Total War сталкиваются с трудностями в игре с характеристиками юнитов, особенно новички, не всегда понимая, какие юниты сильнее, чтобы эффективно побеждать противника. Также данное приложение может быть полезным для реконструкторов исторических сражений в редакторе игры. А потому приложение «Арена» является актуальным.
Продукт предназначен для повседневного использования игроками, которые хотят облегчить себе игру, разобраться в ней, а также программа будет полезна реконструкторам исторических сражений. Это могут быть люди разных возрастов и социального положения. Десктопное приложение «Арена» предназначено для редактирования характеристик юнитов, сравнения юнитов и расчёта соотношения пропорций реальной и игровой численности войск. Приложение ищет в файле заданных пользователем юнитов, показывает их характеристики, сохраняет изменённые характеристики, сравнивает характеристики нескольких юнитов и рассчитывает пропорции численности войск.
Аналоги данного продукта мне неизвестны, а в условиях регулярных отключений сети интернет приложение, независимое от интернета, будет особенно полезным.
## Установка
Перед началом работы с приложением «Арена» необходимо выполнить следующие действия:
1)	Открыть веб-браузер, дважды кликнув по его иконке на рабочем столе.
2)	Ввести в поисковую строку ссылку на скачивание приложения (https://drive.google.com/file/d/1j6EkqsGePJ2-a0n_WdeorHJNmqsIu8si/view?usp=share_link) и кликнуть по клавише Enter, либо пройти по прямой ссылке из данного документа.
3)	На открывшейся странице Google Диск кликнуть по кнопке «Скачать».
4)	В папке «Загрузки» кликнуть дважды по иконке скаченного приложения (с расширением .jar). Приложение автоматически установится на компьютер.
## Использование 
1)	При запуске приложения пользователь попадает в главное меню «Арена», где расположена строка ввода адреса корневой папки игры и кнопки перехода к рабочим окнам.
2)	Для начала работы необходимо ввести путь к корневой папке игры/модификации и кликнуть по кнопке «Найти» – появится сообщение «Путь успешно установлен» (программа будет работать с файлом export_descr_unit.txt с характеристиками юнитов в корневой папке игры). После нажатия кнопки «Ок» будут доступны действия с кнопками «Изменение характеристик» и «Сравнение юнитов» (кнопка «Расчёт пропорций войск» кликабельна изначально, даже с пустым полем ввода адреса корневой папки, поскольку не подразумевает работу с файлами игры).
3)	Для просмотра и редактирования характеристик юнитов (параметры атаки и защиты) необходимо кликнуть по кнопке «Изменение характеристик» - откроется окно «Редактирование характеристик юнита».
4)	Затем необходимо ввести название юнита в строку ввода с плейсхолдером «Наименование юнита» и кликнуть по кнопке «Найти» - будут показаны характеристики найденного юнита и его иконка. Если у юнита отсутствует вспомогательное оружие, оружие дальнего боя, щит или доспехи, то соответствующие пункты будут выделены красным и содержать ноль. Изменять «нулевые» значения атаки и натиска вторым оружием, а также дальность полёта снаряда не рекомендуется во избежание ошибок во время игры.
5)	Для изменения каких-либо характеристик нужно заменить существующие значения на пользовательские путём удаления старых и ввода новых значений и последующим кликом по кнопке «Сохранить».
6)	Клик по кнопке «Сбросить» в любом рабочем окне очищает все поля.
7)	Клик по кнопке «Выйти в меню» в каждом рабочем окне закрывает это окно.
8)	Для сравнения характеристик двух юнитов необходимо кликнуть по кнопке «Сравнение юнитов» в главном меню приложения – откроется окно «Сравнение юнитов».
9)	В окне «Сравнение юнитов» в поля ввода наименований юнитов нужно ввести названия двух сравниваемых юнитов и кликнуть по кнопке «Сравнить» - в поле вывода результатов будут показаны результаты сравнения.
10)	Для расчёта соотношения пропорций реальной численности войск к игровой численности необходимо кликнуть по кнопке «Расчёт пропорций войск» в главном меню – откроется окно «Расчёт пропорций войск».
11)	В окне «Расчёт пропорций войск» в поля ввода числовых значений нужно ввести реальную общую численность войск, реальную численность отдельного отряда и игровую общую численность войск или игровую численность отдельного отряда, а затем кликнуть по кнопке «Рассчитать» - в поле вывода результата появится число, обозначающее игровую численность отдельного отряда, пропорциональную реальной численности отдельного отряда, либо игровую общую численность войск, пропорциональную реальной общей численности войск, в зависимости от заполненных полей.
12)	Для выхода из приложения необходимо кликнуть по крестику выхода в верхней части главного меню.
