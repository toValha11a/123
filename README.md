## 📖 О проекте

Новичкам в Medieval II: Total War бывает сложно понять, какие юниты сильнее, а реконструкторам исторических сражений — подобрать игровую численность войск. «Арена» решает обе задачи и работает **без интернета**:

- 🔍 **поиск юнита** по названию в файлах игры и отображение его иконки;
- ✏️ **редактирование характеристик** (атака, натиск, доспех, щит, умение защиты, дальность) с сохранением в `export_descr_unit.txt`;
- ⚖️ **сравнение двух юнитов** по атаке и защите;
- 🧮 **расчёт пропорций** реальной и игровой численности войск.

## 🚀 Установка

1. Скачайте приложение (`.jar`) с [Google Диска](https://drive.google.com/file/d/1j6EkqsGePJ2-a0n_WdeorHJNmqsIu8si/view?usp=share_link).
2. Откройте папку «Загрузки» и дважды кликните по скачанному файлу `.jar`.

## 🕹️ Использование

1. **Главное меню.** Введите путь к корневой папке игры/модификации (папка с `export_descr_unit.txt`) и нажмите **«Найти»** — появится сообщение «Путь успешно установлен!». После этого станут доступны кнопки «Изменение характеристик» и «Сравнение юнитов». Кнопка «Расчёт пропорций войск» доступна сразу: она не работает с файлами игры.
2. **Изменение характеристик.** Введите название юнита и нажмите **«Найти»** — появятся его характеристики и иконка. Отсутствующие у юнита второе оружие, оружие дальнего боя, щит или доспех выделяются красным и содержат `0`; менять такие значения не рекомендуется. Введите новые значения и нажмите **«Сохранить»**.
3. **Сравнение юнитов.** Введите названия двух юнитов и нажмите **«Сравнить»** — в поле результата появится, какой юнит сильнее в атаке и в защите.
4. **Расчёт пропорций войск.** Введите реальную общую численность войск, реальную численность отряда и **одно** из игровых значений (общая численность или численность отряда), нажмите **«Рассчитать»** — приложение вычислит недостающее игровое значение пропорционально реальному.
5. **«Сбросить»** очищает все поля окна, **«Выйти в меню»** закрывает окно. Для выхода из приложения закройте главное меню.

Подробнее — в [руководстве пользователя](docs/9.-Руководство-пользователя.md).

## 🗂️ Структура проекта

```
src/main/java/arena/
├── Main.java                    # точка входа
├── MainMenu.java                # главное меню, выбор папки игры
├── UnitEditorWindow.java        # редактирование характеристик
├── UnitComparisonWindow.java    # сравнение юнитов

test/java/arena/
└── UnitDataTest.java            # unit-тесты JUnit 5
```
